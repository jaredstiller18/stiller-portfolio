1 of 7 — Tan Lab, CU-Boulder

Closed-loop Hypoxic Air Delivery and Control System

Project Objective

Build a closed-loop rig that automatically holds a subject's blood oxygen saturation in a target band by switching between hypoxic and normoxic air — for altitude-training and physiology research use, not a commercial kit.

Process & Skills

  • Gas path: Hypoxico HYP-123 PSA generator (hypoxic) plus a room-air blower (normoxic) as dual sources
  • Feedback: Masimo Root pulse oximeter streamed over USB serial at 921,600 baud — SpO2 / BPM / PI / RR at 1 Hz
  • Actuation: 4x 2-way solenoid valves driven by a SainSmart FT245R relay board in async bitbang mode via ftd2xx
  • Fail-safe: de-energized state defaults to normoxic air by design
  • Software: Python/Dash dashboard — live vitals plotting, a 15-episode protocol, manual valve override, CSV logging
  • Iterated the controller from a reactive threshold design to a predictive-pulse strategy after characterizing system lag

Results

  • Across 18 tuning sessions, refined the controller to hold SpO2 tightly in the 79–83% band through the second half of each session
  • Measured real desaturation/resaturation dynamics (~0.38%/s vs. up to 5%/s) and used them to eliminate an early 10–14% recovery overshoot
  • Passive fail-safe held throughout testing — every relay or software fault defaulted the subject back to normal air
PID control Solenoid/relay driving Serial protocol integration Safety-first design

2 of 7 — Tan Lab, CU-Boulder

nRF52 BLE Research Instrumentation Platform

Project Objective

Unified three separate pieces of physiology research hardware: a NIRS monitor, a pneumatic cuff inflator, and an electrical stimulator, under one BLE bridge and web dashboard. Allowed the lab to run a single sequenced protocol with shared timestamps, instead of juggling three standalone instruments.

Process & Skills

  • Circuit design: Designed the relay driver circuit and stimulator trigger circuit to control cuff inflation and e-stim via the Nordic's GPIOs.
  • Administrative: Formatted a BOM that was approved, ordered parts, and filed appropriate paperwork (tax refunds). Later produced a Standard Operating Procedure (SOP) and System and Architecture Documentation.
  • Hardware construction: Hand-built and soldered the circuits above, placing them into a working enclosure with USB Micro-C output to computer, BNC output to the e-stim, and a 1/4" audio jack to the cuff inflator.
  • Embedded firmware: Wrote the BLE bridge in Zephyr RTOS (C89, NCS v2.0.0) using the Nordic nRF52-DK, for BT streaming from a Moxy NIRS monitor.
  • Protocol engineering: Implemented the specified research protocol for cuff inflation and precise 5V TTL triggering (~10 ms) for the DS7R stimulator.
  • Full-stack dashboard: Built the live monitoring and protocol-runner interface in vanilla JS / Chart.js / Tailwind, with the entire protocol runnable from one button. Added contingency manual controls for the cuff inflator and e-stim, plus a manual save button on top of automatic hard-drive backups.
Zephyr / C firmware BLE Analog driver design Protocol sequencing

3 of 7 — MCEN 5055: Advanced Product Design

Automated Parking Brake for a Wheeled Walker

Project Objective

To reduce the cognitive and physical load on walker users by implementing an automated sensing and braking system.

Process & Skills

  • Field research: Conducted in-person and virtual interviews with walker users, nurses, and physicians at local retirement homes to determine potential needs. Returned throughout the prototyping stage for continuous user feedback as the concept developed.
  • Ideation: Engaged in a comprehensive brainstorming approach using concept maps, customer journey maps, and affinity diagrams.
  • Administrative and website design: Submitted a BOM to be ordered. Documented the design process (need-finding, ideation, prototyping, reflection, and marketing) on a website platform.
  • Circuit and hardware design: Designed a capacitive brake-trigger circuit using copper tape formed to the walker handles as capacitive sensors. The touch signal was processed through an Arduino Nano, generating a motor response in the braking system. Electronics, drivers, and actuators ran off a portable power source connected to the walker.
  • Hardware construction: Hand-built and soldered the circuit above. Implemented linear actuators into the walker's braking system and a capacitive sensing system in the handles — all fixed to the walker while retaining its foldability and portability.
  • Software design: Wrote and refined code in C/C++ for a touch-threshold brake response, triggering the parking brake when the user loses stable contact with the walker, using an array of handle sensors alongside iterative field tests under observation.
Capacitive sensing Arduino / C++ Actuator integration User research

6 of 7 — Thesis Project: Giovanetti Lab, Williams College

PMMA Barrel Temperature Monitoring System

Project Objective

Build a temperature-monitoring subsystem for a full-scale mockup of the DarkSide-20K dark matter detector's cryogenic core, to protect its PMMA structure from thermal-shock cracking during cooldown.

Process & Skills

  • Finite Element Analysis: Used FEA to determine capsule sizing for slip-fit interference, using material properties to secure the sensor when cooled.
  • Bill of materials and wiring diagrams: Established a BOM for wiring 44 RTDs out of the cryogenic chamber, through a flange, into analog-to-digital converters, then to a central platform.
  • Prototyping: Performed mechanical stress testing on different RTD-capsule-epoxy configurations to determine the best fit for insertion.
  • FEM verification: Performed liquid nitrogen tests using capsules in PMMA to verify FEM simulations and PMMA safety.
  • Instrumentation: Instrumented 44 RTD sensors with 3-wire readout across different panels and depths of the PMMA barrel.
  • Software: Implemented a 3-wire resistance readout into ADCs for each sensor.
  • Dashboard output: Built a live Grafana dashboard for real-time thermal-gradient monitoring during cooling.

Results

Sensor readout held within 1°C agreement across the sensor array during live cryostat cooldown — deemed enough precision to inform a controlled cooling protocol.

RTD/ADC design Cryogenic instrumentation Thermal monitoring

Robotics & controls: Challenge Problems

Project Objective

Four independent challenge problems for Intro to Robotics (CU Boulder), progressing from discrete pathfinding to continuous control, each a self-contained simulation with its own write-up.

Process & Skills

  • CP1 — Multi-robot pathfinding: conflict-resolution algorithms routing robots across a shared grid without collisions

Results

  • CP1: benchmarked two collision-avoidance strategies over 100-run trials

  • CP3: achieved code capable of segmenting jpg files with solid accuracy and reproduce using inverse kinematic on a virtual robotic arm. (see video)
  • CP4: stabilized the inverted pendulum and produced a clean step response with the tuned PD controller
